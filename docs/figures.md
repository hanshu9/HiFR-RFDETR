# README 图示说明

架构图用于 GitHub 首页，流程图位于方法说明中，均由 `scripts/render_readme_figures.py` 生成。PNG 为白底静态展示，SVG 嵌入字形路径，可放大查看。README 提供图注与替代文本。

## 流程示意

`assets/refinement-concept.png` / `.svg` 使用合成输入与手设框解释粗框、精修与融合的关系。

- 输入：96 × 128 × 16 的确定性合成立方体，无随机采样。椭圆中心为 `(67, 49)`，两个半轴分别为 `22`、`29` 像素。
- 光谱：令 `b = linspace(0, 1, 16)`，背景为 `0.12 + 0.12b`，椭圆内部为 `0.36 + 0.35sin²(πb)`。
- 显示：零起始波段 `[10, 6, 2]` 分别对应 R、G、B；各面板使用同一输入与 `[0, 1]` 数值范围，不单独调亮、拉伸或平滑。像素以最近邻显示。
- 粗框：手设 `xyxy = [34, 14, 103, 87]`；融合前精修框：手设 `[44, 19, 90, 79]`。
- 实线框按 `粗框 + 0.5 × (精修框 - 粗框)` 计算，展示默认融合比例的含义。
- 放大面板为 `x ∈ [29, 60]`、`y ∈ [9, 40]` 的原图区域。
- 虚线／实线冗余区分框类型。

## 架构概览

`assets/architecture.png` / `.svg` 按当前 `combined` 模式绘制：光谱适配接入 RF-DETR，全部波段接入高分辨率分支，两路特征使用同一搜索区域做 ROI 融合，再进行边界分布解码与粗框融合。分类 logits 保留。

这是概要图，初始化、坐标补偿和损失权重等细节见 README 的实现说明。浅蓝色标出 ROI 融合、边界分布及解码模块；虚线表示候选框的传递。分类 logits 与检测框作为两个输出分别绘制。

## 重新生成

在已安装 NumPy、Matplotlib 的环境中，从仓库根目录运行：

```shell
python scripts/render_readme_figures.py
```

中文字体使用 Microsoft YaHei、Noto Sans CJK SC 或 Source Han Sans SC 中可用的一种。脚本使用局部样式配置，固定 SVG 标识，输出 PNG 和 SVG 至 `docs/assets/`。PNG 导出为 180 dpi：流程图 2160 × 585 像素，架构图 2232 × 756 像素，面向网页阅读。
